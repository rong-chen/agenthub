# 修复代码模式下 Claude Code 工具执行权限拦截问题

## 问题根因

用户在代码模式下让 Claude Code 修改代码文件时，Claude Code 返回：
`写入 .gitignore 的权限还没有被授予。请在权限提示时选择允许，或者我可以把要修改的内容告诉你手动改。`

根本原因是：
Claude Code 在终端命令行（非交互式 -p 模式）下执行时，默认开启安全权限提示拦截。由于没有交互式 TTY 供用户输入批准确认，Claude Code 判定未授权写入而拒绝执行写文件或 Bash 命令。

## 修复方案

在后台调度 Claude Code CLI 进程时，附加 `--dangerously-skip-permissions` 标志。
该标志指示 Claude Code 在代码工作空间内自动批准由用户在聊天框明确下发的改代码、写文件及运行命令工具请求，免除被中间权限层阻断。
同时强化了对工具执行结果数据结构的解析支持。
